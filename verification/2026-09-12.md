## 0.7.0 Compatibility Fix

The first migration copied the plugin as `plugin.mjs` but left the manifest entry as `./dist/plugin.js`. CodexHost reported:

```text
Harness plugin is unavailable (loadFailed)
error.code: unavailable
stage: pluginLoad
```

Official 0.7.0 plugins use `entry: "plugin.mjs"`. The bundled manifest now uses that value, and `scripts/apply-codexhost-0.7.0.mjs` validates the entry and file before copying. `node --check` passed for the plugin and migration script.

After closing only the CodexHost-launched desktop/shim/runtime chain and relaunching through the normal desktop shortcut chain, the settings connection page changed from `HMHarness 错误 / pluginLoad` to `HMHarness 正常`. CC Switch, codex-image-proxy, and the independent Codex process were not stopped.
