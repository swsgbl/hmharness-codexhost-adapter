## Reproduction

```powershell
npm install -g @openai/codex@0.155.1
npm install -g @hmharness/codexhost-bridge@0.6.5
node scripts/apply-codexhost-0.9.1.mjs
node scripts/apply-codexhost-0.9.1.mjs  # idempotency
pwsh -NoProfile -ExecutionPolicy Bypass -File tools/install-windows.ps1
Copy-Item tools\launch-windows-0.9.1.ps1 $HOME\.codexhost-launch.ps1 -Force
```

Launch `Desktop\CodexHost.lnk`, discover the current ChatGPT CDP listener, wait through the local request-bridge warmup window, then verify the HMHarness agent/model selectors, dedicated icon, a unique real marker, empty composer, Thinking count `0`, and absence of a residual `hmh-codexhost` process.
