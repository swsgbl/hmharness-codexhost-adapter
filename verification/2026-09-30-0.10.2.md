## Windows Launcher Proxy Fix

The 0.10.2 launcher source patch separates proxy handling for the two launch surfaces:

- Chromium receives one explicit proxy argument, selected from `ALL_PROXY`, `HTTPS_PROXY`, or `HTTP_PROXY`, plus an explicit loopback bypass list.
- The Desktop controller receives the helper proxy environment so outbound controller traffic can traverse the managed proxy.
- Host and model traffic remains loopback-only; the patch does not inject proxy variables into the AppX Desktop process environment.

## Desktop 26.924 CDP Target Rule

Desktop 26.924 exposes two app pages:

- Main renderer: `app://-/index.html`
- Hidden overlay: `app://-/index.html?initialRoute=%2Favatar-overlay`

All composer and locale operations must attach only to the exact main-renderer URL. The updated CDP tools no longer select the first URL beginning with `app://`. A live `/json/list` check found both targets, and the renderer diagnostic attached to the main page without exception.
