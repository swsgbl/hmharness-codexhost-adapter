## 中文

- `npm view @hmharness/codexhost-bridge@0.6.1 --registry=https://registry.npmjs.org` 返回 MIT 元数据、4 个文件、8,562 bytes 未压缩大小，且 `repository.directory` 指向 `packages/codexhost-bridge`。

- 在干净项目中使用 `npm install <tarball> --ignore-scripts` 安装官方源 tarball。
- `hmh-codexhost --version` 返回 `{"version":"0.6.1"}`。
- 使用隔离的 `HMH_HOME` 执行 `hmh-codexhost providers --json`，返回预期的 `alt-model` provider 条目。
- 隔离配置中的两个 fake API key 均未出现在两条命令输出中。
- 真实桌面验证使用 CodexHost `0.6.2`、Codex Desktop `26.903.9818.0`、Codex CLI `0.154.0`。
- HMHarness 为 `ready`，列出全部 13 个已配置模型，并选择 `glm / glm-5.3`。
- 连续两个精确 marker turn 分别返回 `HMH_CURRENT_OK_4` 和 `HMH_CURRENT_OK_5`；两个 bridge 进程均退出，完成后可见 Thinking 和 Stop 指示均为 0。
